# S2: Disabling a flecs module disables its observers

Date: 2026-11-09 · Status: **pass**
Test: `spikes/flecs_features/tests/s2_module_disable.rs`

## Method
A flecs module contains one custom phase, one system in that phase, and one observer for a custom event. The test runs a frame and emits the event (baseline: both fire). It then disables the module entity and repeats, then re-enables it and repeats.

## Result (flecs_ecs 0.2.2, Flecs C 4.1.2)
- While the module is disabled, neither the system nor the observer fires.
- Both fire again after it is re-enabled.

This matches the maintainer's statement (design doc 5.5). The [Decided] rule "pause and feature-off are done by disabling modules" holds at the pinned version, and Milestone 0 relies on it: Pong's `play` module is disabled outside `Playing` (`examples/pong/tests/acceptance.rs`, `input_ignored_while_play_module_disabled`).

Re-run this test before bumping Flecs.
